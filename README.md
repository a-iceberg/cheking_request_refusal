# Причина отказа по заявке

По номеру заявки сервис собирает расшифровки звонков из Postgres `voice_ai` и просит модель выбрать одну причину отказа из списка в `data/config.json`. Связка такая: `calls.bid_id` указывает на `transcribations` через `linkedid`. Если текста нет или ответ модели не совпал ни с одной причиной, возвращается код «Не было отказа».

Запрос:

```bash
curl -sk "https://127.0.0.1:8500/refusal_check/<REASON_TOKEN>/<номер заявки>"
```

Ответ — JSON с `llm_reason_id` (код причины из 1С) и `confidence`. Неверный токен приходит обычным текстом, без кода причины.

Модель берётся из `data/config.json`: основная Gemini, запасная Gemini и Anthropic, если кончилась квота. Доступы к базе и ключи моделей лежат в `data/auth.json`. Сервис слушает порт `8500` по HTTPS и использует сеть хоста.

```bash
./compose.sh
docker logs -f refusal_check
```
